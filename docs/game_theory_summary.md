# 神環記 ゲーム理論サマリー

`apps/shinkanki_web/lib/shinkanki_web_web/controllers/page_html/rulebook.html.heex` をソースに、ゲームの流れ・資源循環・カード/才能/エンディング条件を俯瞰できる形で整理したメモです。実装やプレイテストに入る前のルール設計資料として活用してください。

---

## 1. ターン進行と状態遷移

| フェーズ | 主な入力 | 主な処理 | 出力/更新される状態 |
| --- | --- | --- | --- |
| 人代 (hitoyo) | 邪気値、山札トップの人代カード | 邪気に応じて公開枚数 (0〜2→1枚 / 3〜5→2枚 / 6〜8→3枚) を決定。即時効果/猶予効果で F/K/S/邪気 を更新。 | その年の脅威セット、猶予課題、更新後の F/K/S/邪気 |
| 神議り (kamihakari) | 公開中の人代カード、現在の F/K/S/邪気、プレイヤー認識 | 「森を守る年」「文化を守る年」などの方針、最低限守るライン（例: F≥6）を共有 | 営みフェイズの意思決定指針、許容範囲 |
| 営み (itonami) | 方針、営み/みがきカード、空環P、プレイヤー才能 | 1〜3件のアクションを選択 → 必要Pを出し合う → 才能タグ一致で+1ボーナス → 効果を解決 | 更新後の F/K/S/邪気、捨て札、消費されたP |
| 呼吸 (kokyu) | 各プレイヤーの P 所持数 | P ≥ 5 のプレイヤーは最低1つ還流 (P−1 & 任意の F/K/S +1)。追加還流や「最大還流者＝次年才能候補（オプション）」もここで判断 | 新しい P 分布、追加で伸ばした F/K/S、オプションの才能候補 |
| 結び (musuhi) | むすひチップ各1枚 | 同時公開でむすひを渡し合い、2枚以上受け取ったプレイヤーに次年の才能獲得権を付与 | むすひ集計、次年に才能カードを引けるプレイヤー |
| 年送り (toshiokuri) | 年末の F/K/S/邪気/むすひ記録 | F/K/S の 0 未満判定 → いのち指数 L = F + K + S を記録 → 邪気イベント等を処理 → 年トラック +1 | 継続なら次年の初期状態。F/K/S が 0 未満なら敗北エンディング |

### 状態遷移図イメージ

```
人代 ─→ 神議り ─→ 営み ─→ 呼吸 ─→ 結び ─→ 年送り
  ↑                                               │
  └─────────────────────────────────────────────┘（継続時）
                                             ↓
                                        ゲームオーバー
```

## 2. リソースと循環

| リソース | 初期値 | 主な増減タイミング | 備考 |
| --- | --- | --- | --- |
| 森 (F) | 5 | 人代 (減少) / 営み・みがき (増減) / 呼吸 (+1先として選択) | 0 未満で即敗北 |
| 文化 (K) | 5 | 上に同じ | 〃 |
| コミュニティ (S) | 5 | 上に同じ | 〃 |
| 邪気 | 6 | 人代で増加、みがき/特定アクションで減少 | 値に応じて人代枚数が変わる |
| 空環 (P) | 各プレイヤー 3 | 営みで支払い、呼吸で還流、イベントで獲得/喪失 | P ≥ 5 で還流義務 |
| むすひ | 年末に配布 | 結びフェイズで配布・記録 | 才能成長トリガー |

### 循環メモ

* **P → F/K/S**: 呼吸フェイズで還流すると F/K/S のいずれか +1。プレイヤーの「重さ」調整と世界へのめぐりが同時に起こる。
* **むすひ → 才能**: むすひ 2 枚以上を受けたプレイヤーは次年の初めに才能カード 2 枚から 1 枚を追加。オプションで「呼吸フェイズで最多還流者」も同様の権利を得る。
* **邪気 → 人代枚数**: 邪気 0〜2:1枚 / 3〜5:2枚 / 6〜8:3枚。邪気を下げると人代の重圧が減り、上がるとフェイズ開始時の難易度が高まる。

## 3. カード/トークン/才能一覧

| 種別 | 役割/効果 | 補足 |
| --- | --- | --- |
| 人代カード | 現代の逆風。即時で F/K/S/邪気 を悪化させたり、「年末までに○○しないとペナルティ」などの猶予型を提示 | 邪気値で引く枚数が変わる |
| 営みカード | その年に実行する行動。P コストと効果、関連タグが書かれている | 方針や人代カードを見ながら 1〜3 枚選択 |
| みがきカード | 世界を浄化・回復する大技。F/K/S を回復しつつ邪気を下げる、ペナルティ軽減など | 才能ボーナスが刺さりやすい |
| 才能カード | プレイヤーの得意/役割タグ。アクションタグと一致すると効果に +1 のボーナス | 最大 3 枚まで所持 |
| 空環トークン (P) | 行動コスト兼循環資源。貯め込みすぎると呼吸フェイズで強制還流 | 還流時は任意の F/K/S を +1 できる |
| むすひチップ | 感謝と結びの可視化。年末に配布し、2 枚以上受けたプレイヤーが才能成長 | 同時公開推奨 |

## 4. 才能システム

| 項目 | 内容 |
| --- | --- |
| 初期才能 | ゲーム開始時に 3 枚引き、1 枚を選んで表向きに置く。はまらなければ 1 回だけリドロー可。 |
| トリガー (正式) | 結びフェイズでむすひチップを 2 枚以上受け取ったプレイヤー。次の年の初めに才能カード 2 枚から 1 枚を追加。 |
| トリガー (オプション) | 呼吸フェイズでその年いちばん多く P を還流したプレイヤーを「才能に気づく候補」として扱い、同様に次年才能を追加。 |
| 上限/入れ替え | 所持上限は 3 枚。4 枚目以降のトリガーを満たした場合は新規 2 枚から 1 枚を採用し、既存の 1 枚を戻す入れ替えルールに切り替えてもよい。 |

## 5. エンディングとショートゲーム

| 条件 | 処理/エンディング |
| --- | --- |
| F/K/S のいずれかが 0 未満 | 即敗北。状況をもとに「どんな終わり方になったか」を語り合う。 |
| 20 年完走 | 年送りフェイズ後、最終 F/K/S から `L = F + K + S` を計算し、L の値に応じたエンディングテキストを読む（テキストは別冊予定）。 |
| ショートゲーム推奨設定 | 初回は 10 年で終了、人代/みがきカードをカテゴリごとに 8〜10 枚程度に絞り、邪気イベントをオフにして学習コストを下げる。慣れてきたらカード種類やイベントを増やし、邪気 8 で八岐大蛇イベントなどを追加。 |

## 6. 次に深掘りしたい点

1. **フェーズごとの UI モック/要件**  
   - 例: 人代フェイズでは邪気値→展開枚数→公開カードの即時/猶予効果を時系列で見せる。
2. **カードデータスキーマ**  
   - 人代/営み/みがき/才能の JSON 構造とタグ体系を定義し、ゲームサーバ実装に橋渡し。
3. **エンディング表の具体値**  
   - L 値ごとの分岐 (例: 40+ = 「神々の祝福」など) と演出方針の文書化。
4. **バランス調整メモ**  
   - F/K/S/邪気/P の推移を仮想プレイで追跡し、フェーズ間の難易度調整ポイントを洗い出す。
